공급전 안전점검 신청서 검토 도구

⚠️ 이 도구는 브라우저에서 Anthropic API로 직접 요청합니다. API 키는 사용자의 브라우저(localStorage)에만 저장되며 어디에도 전송되지 않지만, 공용 컴퓨터나 공개 배포 환경에서는 키가 노출될 수 있으니 개인/사내 용도로만 사용하세요.
